Sixteen-bit unsigned integers with explicit arithmetic and conversion failure policies.

## When to use
Use `u16` when a file format, protocol, or compact data structure specifies exactly sixteen
unsigned bits. Use `usize` for in-memory lengths and indices that follow the target.

## Details
Ordinary arithmetic, narrowing conversions, division by zero, and invalid shift counts trap.
`checked*` reports invalid arithmetic with [`Option`](/docs/std/option#Option), `wrapping*` computes modulo 2^16, and
`saturating*` clamps at [`MIN`](#MIN) or [`MAX`](#MAX). Right shift inserts zero bits.

Decimal [`parse`](#parse) consumes the entire input and distinguishes malformed text from range
overflow. Use [`Format`](/docs/std/format#Format) with `Format.display` for defaults or `Format.displayWith` for explicit
options. Both operations stream through a mutable `Writer` without `Allocator`.

## Examples
### Recover from a narrowing conversion
```silk
import silk.option { Option }

import silk.u16

import silk.u8

pub fn main() -> i32 {
  let narrowed = u16.checkedToU8(300)
  let value = move narrowed
    |> Option<u8>.unwrapOr(42)
  return u8.toI32(value)
}
```

Import as `u16` with `import silk.u16`.

## `parse`

```silk
pub fn parse(text: string) -> Result<u16, ParseError>
```

Reads the complete text as an unsigned decimal `u16`.

### Details

A failure contains `silk.format.NotANumber` for empty text, a sign, a non-digit, or trailing
bytes. It contains `silk.format.OutOfRange` if the number is outside the `u16` range.

Profiles: `aarch64-apple-darwin`, `aarch64-unknown-linux-gnu`, `aarch64-unknown-linux-gnu-no-libc`, `x86_64-unknown-linux-gnu`, `x86_64-unknown-linux-gnu-no-libc`, `wasm32-unknown-unknown`.
