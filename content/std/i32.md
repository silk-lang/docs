Thirty-two-bit signed integers and the default type of context-free integer literals.

## When to use
Use `i32` for ordinary signed whole-number calculations whose range is known to fit, and when a
stable 32-bit representation matters. Choose `isize` for pointer-sized offsets and `i64` for a
wider fixed range.

## Details
Ordinary arithmetic, narrowing conversions, division by zero, and invalid shift counts trap.
`checked*` reports invalid arithmetic with [`Option`](/docs/std/option#Option); `wrapping*` computes modulo 2^32;
`saturating*` clamps at [`MIN`](#MIN) or [`MAX`](#MAX). Signed right shifts preserve the sign bit.

Decimal [`parse`](#parse) rejects trailing bytes and separates invalid syntax from out-of-range input.
Use [`Format`](/docs/std/format#Format) with `Format.display` for defaults or `Format.displayWith` for explicit options.
Both operations stream through a mutable `Writer` without `Allocator`.

## Gotchas
[`MIN`](#MIN) has no positive i32 counterpart. Use [`wrappingNegate`](#wrappingNegate) or [`saturatingNegate`](#saturatingNegate) for its
negation boundary. Use [`checkedDivide`](#checkedDivide) when division by `-1` can receive [`MIN`](#MIN).

## Examples
### Select an overflow result explicitly
```silk
import silk.i32

import silk.option { Option }

pub fn main() -> i32 {
  let checked = i32.checkedAdd(i32.MAX, 1)
  let recovered = move checked
    |> Option<i32>.unwrapOr(42)
  if i32.wrappingAdd(i32.MAX, 1) != i32.MIN {
    return 1
  }
  if i32.saturatingAdd(i32.MAX, 1) != i32.MAX {
    return 2
  }
  return recovered
}
```

Import as `i32` with `import silk.i32`.

::Anchor{id="parse"}

## `parse`

```silk
pub fn parse(text: string) -> Result<i32, ParseError>
```

Reads the complete text as a signed decimal `i32`.

### Details

A failure contains `silk.format.NotANumber` for empty text, a leading `+`, a non-digit, or
trailing bytes. It contains `silk.format.OutOfRange` if the number is outside the `i32` range.

Profiles: `aarch64-apple-darwin`, `aarch64-unknown-linux-gnu`, `aarch64-unknown-linux-gnu-no-libc`, `x86_64-unknown-linux-gnu`, `x86_64-unknown-linux-gnu-no-libc`, `wasm32-unknown-unknown`.
