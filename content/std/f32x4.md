Operations on `simd<f32, 4>`: four 32-bit float lanes in one 128-bit vector.

## When to use
Use this module to work on four `f32` values at once. Use [`load`](#load) and [`store`](#store)
to move lanes between a slice and a vector, a lane comparison such as [`lanesEqual`](#lanesEqual) to make
a `mask<4>`, and `silk.simd.mask4` to test that mask.

## Details
The operators `+`, `-`, `*`, `/` and `%` apply lane by lane and follow IEEE 754 as the
`f32` operators do. `==` is true only when every lane is equal, and a NaN lane is never
equal. [`reduceAdd`](#reduceAdd) adds lanes in order, so it gives the same result on every target.
Lane `0` is at the lowest address in memory.

## Examples
### Scale every lane and add the results
```silk
import silk.simd.f32x4

pub fn main() -> i32 {
  let values = f32x4.fromArray([1.0, 2.0, 3.0, 4.0])
  let doubled = f32x4.mulAdd(values, f32x4.splat(2.0), f32x4.splat(0.0))
  if f32x4.reduceAdd(doubled) != 20.0 {
    return 1
  }
  return 0
}
```

Import as `f32x4` with `import silk.simd.f32x4 as f32x4`.

## `shuffle`

```silk
pub fn shuffle(left: simd<f32, 4>, right: simd<f32, 4>, static indices: [usize; 4]) -> simd<f32, 4>
```

Returns a vector whose lane `i` is lane `indices[i]` of `left` followed by `right`.

### Details
An index below [`LANES`](#LANES) selects from `left`, and an index from [`LANES`](#LANES) to `2 * LANES - 1`
selects from `right`. The indices are static, so each call is one fixed lane permutation.
