Operations on `simd<u64, 2>`: two unsigned 64-bit integer lanes in one 128-bit vector.

## When to use
Use this module to work on two `u64` values at once. Use [`load`](#load) and [`store`](#store)
to move lanes between a slice and a vector, a lane comparison such as [`lanesEqual`](#lanesEqual) to make
a `mask<2>`, and `silk.simd.mask2` to test that mask.

## Details
The operators `+`, `-`, `*`, `/`, `%`, `&`, `|`, `^` and `~` apply lane by lane and trap
exactly where the `u64` operator traps. Use [`wrappingAdd`](#wrappingAdd) or [`saturatingAdd`](#saturatingAdd) when
overflow is expected. `==` is true only when every lane is equal.
Lane `0` is at the lowest address in memory.

## Examples
### Find the first matching lane
```silk
import silk.simd.mask2
import silk.simd.u64x2

pub fn main() -> i32 {
  let mut values: [u64; 2] = u64x2.toArray(u64x2.splat(0))
  values[1] = 3
  let hits = u64x2.lanesEqual(u64x2.fromArray(values), u64x2.splat(3))
  if !mask2.any(hits) || mask2.firstSet(hits) != 1 {
    return 1
  }
  return 0
}
```

Import as `u64x2` with `import silk.simd.u64x2 as u64x2`.


Returns a vector whose lane `i` is lane `indices[i]` of `left` followed by `right`.

### Details
An index below [`LANES`](#LANES) selects from `left`, and an index from [`LANES`](#LANES) to `2 * LANES - 1`
selects from `right`. The indices are static, so each call is one fixed lane permutation.
