Operations on `simd<u16, 16>`: sixteen unsigned 16-bit integer lanes in one 256-bit vector.

## When to use
Use this module to work on sixteen `u16` values at once. Use [`load`](#load) and [`store`](#store)
to move lanes between a slice and a vector, a lane comparison such as [`lanesEqual`](#lanesEqual) to make
a `mask<16>`, and `silk.simd.mask16` to test that mask.

## Details
The operators `+`, `-`, `*`, `/`, `%`, `&`, `|`, `^` and `~` apply lane by lane and trap
exactly where the `u16` operator traps. Use [`wrappingAdd`](#wrappingAdd) or [`saturatingAdd`](#saturatingAdd) when
overflow is expected. `==` is true only when every lane is equal.
Lane `0` is at the lowest address in memory.

## Examples
### Find the first matching lane
```silk
import silk.simd.mask16
import silk.simd.u16x16

pub fn main() -> i32 {
  let mut values: [u16; 16] = u16x16.toArray(u16x16.splat(0))
  values[15] = 3
  let hits = u16x16.lanesEqual(u16x16.fromArray(values), u16x16.splat(3))
  if !mask16.any(hits) || mask16.firstSet(hits) != 15 {
    return 1
  }
  return 0
}
```

Import as `u16x16` with `import silk.simd.u16x16 as u16x16`.

```silk
pub fn shuffle(left: simd<u16, 16>, right: simd<u16, 16>, static indices: [usize; 16]) -> simd<u16, 16>
```

Returns a vector whose lane `i` is lane `indices[i]` of `left` followed by `right`.

### Details
An index below [`LANES`](#LANES) selects from `left`, and an index from [`LANES`](#LANES) to `2 * LANES - 1`
selects from `right`. The indices are static, so each call is one fixed lane permutation.
