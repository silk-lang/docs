# Silk: Get started

## Overview

Four short pages take you from no Silk at all to a running program and an editor that highlights it. Read them in order.

| Page | What you do there |
| --- | --- |
| 1. Install | Run `install.sh` to put `silk` and its standard library in `~/.silk`, set up Clang and your `PATH`, and check the signature. Also covers pinning, upgrading and uninstalling. |
| 2. Your first program | Create a package with `silk init`, read the files it makes, pass arguments with `silk run --`, set the exit status, and build an executable. |
| 3. A tour of Silk | Read one 85-line program that shows structs, unions, `match`, borrows, moves and an effect that can fail, with the reference page for each. |
| 4. Editor setup | Get highlighting in VS Code, Zed, tree-sitter editors and web pages. A language server is planned but not here yet. |

After this, the Silk book teaches the language in order, and the Language reference has the full rules.
