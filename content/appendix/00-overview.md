# Silk: Appendix

## Overview

Five lookup pages for the language and its compiler.

- **Keywords**: the 38 reserved keywords and 16 contextual words, each with a one-line meaning and its reference page.
- **Operators**: operator precedence and associativity, and the interface each overloadable operator maps to.
- **Diagnostic codes**: every LEX, PAR, MOD, OWN and SEM code, with a failing program, the exact output and the fix, plus the codes this compiler never reports.
- **Grammar summary**: a compact grammar of declarations, types, statements, expressions and patterns, with the tricky rules checked by experiment.
- **Glossary**: owner, move, loan, lifetime, row, requirement, service, provider, role, directive, suspension, trap, profile, target, WASI and other terms, each with its reference page.
